# Mathematics for Engineering II

Course site for Mathematics for Engineering II (Year 2, Dyson School of Design Engineering, Imperial College London).
Published with GitHub Pages from the root of the `main` branch.

The pages are generated; edit the sources, not the HTML:

- `content.py`: sessions, exercises, videos, examination date.
- `handbook.html`: the handbook text.
- `site.css`: the stylesheet.
- The topic map data comes from the module folder (`topic_map/interactive_source/`).

Slides, exercise sheets and examination papers are not published here; they are on Canvas.
